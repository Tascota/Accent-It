# Accent It 测试记录

本文保存 Accent It 的实际运行测试记录，**不构成兼容性承诺**。快速开始见 [README](../README.md)，完整使用细节见 [使用说明](USAGE.md)，开发进度和构建命令见 [DEVELOPMENT](DEVELOPMENT.md)。

测试环境：Windows 11，单显示器，150% 缩放。界面测试使用临时隔离副本和测试快捷键，不操作当时正在运行的 Accent It 实例；涉及插入的测试会临时改写剪贴板，并在开始前提示，均不读取测试前的剪贴板内容（较早的测试使用预先写入的固定文本作为哨兵）。

> 以下记录按测试当时版本存档。之后界面做过文字精简，窗口尺寸和按钮名称也有调整，个别数值来自旧版布局；当前紧凑窗口为 460×430 DIP，测试所验证的流程和结论仍然有效。

| 场景 | 测试方式 | 实际结果 |
| --- | --- | --- |

### 记事本中的真实插入

使用默认全局快捷键 `Ctrl+Alt+Space`，在临时记事本中依次插入，每次通过 UI Automation 读取目标文本。四次插入的预览和路径均正确：

| 输入路径 | 目标文本新增码点 |
| --- | --- |
| `M + 倒转` | U+019C |
| `i + j + 合字` | U+0133 |
| `o + e + 合字` | U+0153 |
| `s + s + 合字` | U+00DF |

四次插入后记事本中的完整序列为 `U+019C U+0133 U+0153 U+00DF`。测试结束后关闭了由测试启动的记事本和 Accent It 进程，并删除临时文件。

未测试：这些新模式在 Edge、VS Code、Chrome、Windows Terminal、管理员权限目标或输入法组合输入状态下的行为；紧凑窗口中的 Backspace 删除顺序和第二字母焦点切换没有单独做 UI 自动化断言；NFD 下的变形路径由单元测试覆盖，没有在真实目标应用里逐项验证。

以下测试在 2026-10-21 进行。测试使用临时隔离副本和测试快捷键，没有操作当时正在运行的 Accent It 实例；没有执行插入，也没有读写剪贴板。

| 场景 | 测试方式 | 实际结果 |
| --- | --- | --- |
| 四边布局 | 用 UI Automation 读取窗口、预览和每个符号按钮的物理矩形 | 窗口为 460×430 DIP；上方 12 个符号在同一排，下方 9 个在同一排，左侧 3 个、右侧 2 个；所有上方符号位于预览上方、下方符号位于预览下方，左右符号分别位于预览两侧 |
| 符号按钮 | 读取按钮宽度并截图检查 | 每个按钮约 28 DIP 宽，只显示虚线圈加符号；名称没有出现在按钮正文中，悬停提示保留名称和码点 |
| 主窗口 → 紧凑窗口（按钮） | 点击“紧凑窗口 (F2)” | 主窗口隐藏，紧凑窗口打开；因没有外部目标，顶部显示“无外部目标，仅复制” |

| 紧凑窗口 → 主窗口（F2） | 聚焦紧凑窗口后按 F2 | 紧凑窗口关闭，主窗口显示并保留输入 |
| 主窗口 → 紧凑窗口（F2） | 聚焦主窗口后按 F2 | 紧凑窗口打开并保留输入 |
| 紧凑窗口 → 主窗口（按钮） | 点击“完整编辑器 (F2)” | 与 F2 切换结果相同 |

F2 由测试脚本通过系统 `SendKeys` 发送，应用代码使用正常的窗口按键处理。该测试没有覆盖自定义目录中新增位置 id 的四边布局，只覆盖了默认目录和一条纯逻辑单元测试中的 `top/bottom/left/right/misc` 映射。

## 深夜模式测试记录

以下测试在 2026-10-21 进行。测试使用临时隔离副本；没有执行插入，也没有读写剪贴板。亮度值为截图区域的平均值，0 为纯黑、255 为纯白；括号内是同一区域的平均 RGB，并额外检查蓝色通道高于红色通道，避免只验证“够暗”却漏掉色调。

| 场景 | 测试方式 | 实际结果 |
| --- | --- | --- |
| 主窗口浅色 | 启动临时副本，主题文件不存在 | 内容区背景亮度 243.2，标题栏 242.8；界面为浅色 |
| 主窗口切换到深夜模式 | 点击“深夜模式”按钮 | 内容区背景亮度 17.5（RGB 11,18,32），标题栏 17.5（RGB 11,18,32）；两个按钮文字变为“日间模式 / 紧凑窗口 (F2)”；没有使用快捷键 |
| 主题文件 | 切换后读取临时副本的 `Data/theme.json` | 文件被创建，内容包含 `"theme": "dark"`；没有改动 `settings.jsonc` |
| 紧凑窗口跟随主题 | 在深夜模式下点击“紧凑窗口 (F2)” | 紧凑窗口内容区亮度 17.5（RGB 11,18,32），标题栏 17.5（RGB 11,18,32）；顶部按钮显示“浅色” |
| 紧凑窗口切回浅色 | 点击紧凑窗口顶部“浅色” | 紧凑窗口内容区亮度 243.2，标题栏 242.9；返回主窗口后主窗口也为浅色 |

# Accent It

Accent It 是一个 Windows 桌面工具，用于从基础字母组合出 Unicode 字符：既可以添加组合附加符号，也可以用“倒转”“加钩”“合字”等抽象操作得到特殊字母，并输出 NFC 或 NFD 结果。

**声明：**本项目完全基于 vibe coding，仅以满足本人个人使用需求为目标。请务必不要用于关键生产环境。

## 主要功能

- **完整编辑器**：分组选择组合符号、实时预览、核对码点并复制结果。
- **快速输入窗口**：通过全局快捷键在其他应用前呼出，尝试把结果粘贴到当前光标位置。
- 字母变形路径，例如 `M + 倒转 → Ɯ`、`i + j + 合字 → ĳ`；没有匹配路径时明确提示。
- 可搜索的“其他字符”列表，补足没有通用变形关系的字符（如 `ð`、`þ`）。
- 支持 NFC / NFD、浅色 / 深夜主题、系统托盘。
- 符号目录、变形路径、其他字符和全局快捷键均可通过 JSONC 修改。

## 环境要求

- Windows（已在 Windows 11 上测试；其他版本未完整验证）
- 从源码运行需要 .NET 10 SDK（版本以 [global.json](global.json) 为准）
- 运行已构建程序需要 .NET 10 Desktop Runtime

当前没有安装包、开机启动或自动更新。

## 运行

在仓库根目录执行：

```bash
dotnet run --project src/AccentIt
```

首次启动会在可执行文件旁的 `Data` 文件夹创建快捷键设置；切换过的主题保存在同一目录的 `theme.json`。构建与测试命令见[开发记录](docs/DEVELOPMENT.md)。

## 快速使用

### 完整编辑器

1. 输入一个基础字母。
2. 在“组合符号 / 字母变形 / 其他字符”中选择输入方式，右侧会实时预览。
3. 选择 NFC 或 NFD，点击“复制结果”。
4. 按 F2 或点击“紧凑窗口”可在两个窗口间切换，当前输入会保留。

### 快速输入窗口

1. 在目标应用中点好准备输入的位置。
2. 按全局快捷键（默认 `Ctrl+Alt+Space`）呼出紧凑窗口。
3. 输入字母，选择符号或变形，按 Enter 尝试插入。
4. 插入后窗口保持打开，可继续输入；Esc 取消并关闭。
5. 如果没有插入成功，可按 `Ctrl+V` 手动粘贴，或使用“复制结果”。

关闭主窗口会隐藏到系统托盘，程序继续响应全局快捷键；右键托盘图标可以退出。主题按钮位于窗口右上角或紧凑窗口顶部。

更完整的按键、插入流程、托盘和主题说明见[详细使用说明](docs/USAGE.md)。

## 配置

程序从可执行文件旁的 `Data` 目录读取配置：

| 文件 | 作用 |
| --- | --- |
| `Data/accents.default.jsonc` | 符号、字母变形路径和其他字符 |
| `Data/settings.jsonc` | 全局快捷键，首次运行时创建 |
| `Data/theme.json` | 上次选择的界面主题 |

修改配置后需要重启程序。旧版 `Data/accents.jsonc` 会保留但不再读取。文件位置、JSONC 格式、字段说明和快捷键规则见[配置说明](docs/CONFIGURATION.md)。

## 隐私与限制

- 程序在本地运行，当前版本没有联网或遥测功能。
- 插入时会备份剪贴板并捕获目标窗口和焦点信息；这些内容不会被上传。被识别为密码框时，不读取内容，也不自动插入。
- 自动插入只表示已经尝试发送 Ctrl+V，不能保证所有应用接受。目前只在 Windows 11 记事本和隔离的 Edge 临时页面中实测通过。
- 管理员权限目标、光标定位、剪贴板恢复等限制详见[详细使用说明](docs/USAGE.md)。
